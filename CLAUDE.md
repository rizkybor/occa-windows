# OCCA for Windows

Windows edition of OCCA (Orienteering Cakra CAD Application), PT. Jendela Cakra Digital. All product decisions are in
`docs/BRD.md` and `docs/PRD.md`; read them before changing scope. Milestones: PRD §11.

## Decisions (from BRD/PRD)

- .NET 8 (C#) + WinUI 3 (Windows App SDK 1.8) + Win2D/Direct2D. Windows 11 24H2 (build 26100) minimum, x64 + ARM64.
- Basemap: Esri World Imagery via ArcGIS Location Platform (API key from config). Offline rules: `docs/esri-offline-imagery.md`.
- Distribution: Microsoft Store (MSIX, Microsoft signs) + MSI (WiX 5) downloaded from HRIS, unsigned in beta.
- Licensing: HRIS keys `OC7{plan}-XXXX-XXXX-XXXX-NNNN` (platform digit 7), platform value `windows`, Ed25519-signed
  token verified offline, device ID = SHA-256 of MachineGuid + salt, token stored with DPAPI in `%LOCALAPPDATA%\OCCA`.
- UI language English. Projects in `%LOCALAPPDATA%\OCCA\Projects\<id>.cakra` (same layout as Mac).

## Architecture

```
OCCA.Windows.sln
├─ src/Occa.Core         net8.0 class library: models, geometry, symbols, geodesy, courses, contours,
│                        readers/writers (.occa LZFSE, OCAD, OMAP, GeoTIFF, GPX, IOF XML), course planner (Course/),
│                        contours + DEM readers (Contour/), license token/validity
├─ src/Occa.Render       net8.0-windows: Win2D map renderer, PDF writer (CMYK), raster exporter
├─ src/Occa.App          WinUI 3 app: shell, panels, tools, input, dialogs, licensing UI, updater
├─ tests/Occa.Core.Tests xUnit: ported CakraCore tests + golden files (Fixtures/)
├─ installer/wix         WiX 5 MSI; MSIX comes from Occa.App (single-project MSIX)
├─ build/                CI helper scripts (version stamping, key injection)
└─ docs/                 BRD, PRD, spikes, testing guide
```

Key code paths:
- `.occa` = `CPENCIL1` + LZFSE stream of `[count][len,path,len,data]…` (little-endian). Decoder:
  `Occa.Core/Compression/LzfseDecoder.cs` (+ `LzvnDecoder.cs`), container: `Occa.Core/Project/ProjectArchive.cs`.
  Fixtures in `tests/Occa.Core.Tests/Fixtures` were generated by CakraCore itself; regenerate with the same code when
  the Mac format changes.
- Package files: `project.json`, `strokes.json`, `features.json`, `courses.json`, `field.json` (envelopes
  `{version, <key>}` except `project.json`), optional `thumbnail.jpg`, `course-images/`, `field-photos/`, `imagery/`
  (per-device cache, excluded from `.occa`).
- Basemap: `Occa.Core/Basemap/EsriWorldImagery.cs`, `WebMercator.cs`, `TileCache.cs` (honours HTTP caching headers);
  app config in `Occa.App/AppSettings.cs`.
- Models (ported 1:1 from CakraCore, same JSON): `Occa.Core/Project/Project.cs` + `ProjectPackage.cs`,
  `Vector/Feature.cs`, `Stroke.cs`, `Symbols.cs` (MapSymbol, AreaPattern, LineDecoration, OccaSymbolFile),
  `Sheet/MapSheet.cs`, `Geometry/Utm.cs`. All models carry `[JsonExtensionData]` for unknown fields.
- Symbol sets: `Occa.Core/Resources/SymbolSets/*.occasym` are **generated by CakraCore** (`OccaStandardSymbols`);
  never edit by hand. Regenerate with the Mac repo when the specs change (the generator lives in the session
  scratchpad; recreate from `OccaStandardSymbols.isomFile().encoded()` etc.). Loaded by `Vector/StandardSymbolSets.cs`.
- Drawing: `Vector/ColorHierarchy.cs` (paint order), `Vector/SymbolOrnaments.cs` (patterns, decorations),
  `Render/MapScene.cs` (renderer-independent items) → `Occa.Render/MapRenderer.cs` (Win2D), `BasemapLayer.cs`
  (Esri tiles / GeoTIFF), `MapTransform.cs`. The app's `Views/MapView.xaml` hosts the CanvasControl.
- Editing (M2): `Vector/FeatureEdit.cs` (nodes, handles, rotation, change symbol, insert/split, parallel, reverse),
  `FeatureFollow.cs` (path positions, follow object, freehand guide trace), `ShapeCut.cs` (boolean cut engine on
  exact bezier outlines: area − shape, split along a path, line − box), `FeatureMerge.cs` (join lines, unite areas,
  polygon-union fallback, fill line with area), `FeatureCorners.cs` (corner tool), `RotationSnap.cs`. Feature is a
  mutable class: verb methods mutate in place, `Clone()` gives Swift-style value copies. Tests are ports of the
  CakraCore suites (FeatureCutTests, AreaHolesTests, FeatureCornersTests, FeatureMergeTests…).
- Saving: `Compression/LzfseEncoder.cs` writes uncompressed LZFSE blocks (valid for Apple's decoder; verified on
  Mac); `ProjectArchive.Pack` builds `.occa`; `ProjectPackage.Write` writes the package JSON byte-identical to Mac.
- Output (M3): `Export/GeoPdfExporter.cs` (hand-written Geospatial PDF, DeviceCMYK from the IOF table via
  `IofColors`, byte-compatible with the Mac exporter), `Export/OmapWriter.cs` + `DxfWriter.cs` + `ExportTypes.cs`
  (symbol table, requests, world file, sidecars); raster drawing lives in `Occa.Render/RasterExporter.cs` (Win2D).
  Import: `Import/OcadReader.cs` (OCAD 10–2018), `OmapReader.cs`, `OmapSymbolSet.cs`, `MapFileImport.cs`.
  OOM sets in `tests/.../Fixtures/oom` are GPL test inputs only, never shipped.
- Golden tests: `tests/Occa.Core.Tests/Fixtures/symbol-display.occa` + `.golden.json` were computed by CakraCore;
  `GoldenDisplayTests` must stay green. When porting more of CakraCore, extend the generator and the goldens.
- Courses (M4, namespace `Occa.Core.Courses`, folder `Occa.Core/Course`): `Course.cs` (ControlPoint, Course, CourseSet
  with codes/loads/warnings/renumber, SpecialInstruction "15.x", FinishRoute "16.x", LegGap, CoursePrintLayout,
  CourseAppearance), `ControlDescription.cs` (IOF 2024 catalog `IofSymbols`, 2018 → 2024 migration run by
  `IJsonOnDeserializing/Deserialized` when `descriptionFormat` is missing), `CourseItem.cs` (text/shapes/images + IOF
  course symbols 702–715 drawn from the built-in symbol sets), `CourseOverprint.cs` (CourseStyle, CourseMark records,
  `Make`, `Levels` = lower/upper purple), `DescriptionSheet.cs`, `IofPictogram.cs` (pictograms + PDF operators),
  `IofXmlExporter.cs`, `CourseImages.cs` (+ a minimal PNG decoder). `ProjectDocument.Courses` is a typed `CourseSet`;
  `courses.json` is written only when the set has content (like Mac). Import: `Import/OcadCourseReader.cs`,
  `OmapReaderCourses.cs`, `CourseFileImport.cs`. The PDF exporter draws the overprint in the colour order and the
  description table (`GeoPdfExporter.OverprintContent/DescriptionTable`).
- Contours (M4, `Occa.Core/Contour`): `ContourGenerator.cs` (ContourSettings in `Project.contourSettings`, ContourLine,
  marching squares + Douglas–Peucker + Chaikin), `DemGrid.cs` (`dem.json` + `dem.bin` float32 LE in the package),
  `DemReaders.cs` (ESRI ASCII grid, GeoTIFF with Deflate/LZW/predictors, AWS Terrain Tiles Terrarium, GeoJSON
  contours), `ContourExport.cs` (Shapefile, KML, KMZ via a store-only ZipWriter).
- Editing UI (M6 = beta readiness; the deferred M2 UI): `Vector/EditHistory.cs` (undo/redo of whole-document snapshots,
  `SymbolFeatures` builds line/area/point objects from a `MapSymbol` with the Mac's default names), `Feature.SetWidth`.
  App: `Views/NewProjectDialog.xaml` (name, scale, A4 orientation, start lat/lon → Select Area mode), `Views/SymbolPanel.xaml`
  (built-in set of the sheet standard, search, "Apply to selection"), `Occa.Render/SelectionRenderer.cs`, and the tools in
  `Views/MapView.xaml(.cs)`: Navigate H, Move V, Node A, Pen P, Freehand F, Rectangle M, Ellipse L, Point T, Sketch N, Eraser E;
  Esc/Enter/Delete, Ctrl+Z/Y/S/D/A, right-click menu, drag moves objects/points/handles, autosave 600 ms, thumbnail on
  save. Select Area mode: frame follows the view centre and the UTM zone follows the location until "Lock area". FR-W4 window
  bounds and FR-W8 file activation live in `MainWindow`/`App.xaml.cs` (`UserSettings` holds the bounds).
- Licensing (M5, `Occa.Core/License`): `Ed25519.cs` (pure C# RFC 8032 verify + sign for tests), `LicenseToken.cs`
  (payload, base64url, `Verify` with the back office public key, product `occa`, platform `windows`), `LicenseKey.cs`
  (`OC7{plan}-…`, platform digits 3/5/7), `LicenseValidity.cs`, `LicenseDeviceId.cs` (salted SHA-256, UUID-shaped),
  `LicenseApi.cs` (HRIS `/api/licenses/occa/*`, requests send `platform: "Windows"`, `releases/latest` for updates),
  `LicenseEngine.cs` (state machine with injected `ILicenseStore`/`ILicenseApi`/clock; tests use fakes), `ProFeature.cs`
  + `FreeLimits` (Starter: 3 projects, 1:4000/1:10000, 4 courses). App: `License/DpapiLicenseStore.cs` (DPAPI files in
  `%LOCALAPPDATA%\OCCA\license`), `WindowsDevice.cs` (MachineGuid → device id), `AppLicense.cs` (singleton, re-check
  timer, `Require(feature)` opens `Views/LicenseDialog.xaml`), `UpdateChecker.cs`; gates in MainWindow (project limit,
  map import), MapView (contours, course import, IOF XML, raster/vector export, PDF credit on Starter), CoursePanel
  (course limit). Debug builds are Lifetime unless started with `--license key`; `--license-api <url>` / `OCCA_LICENSE_API`
  pick the server. HRIS still needs the Windows platform (digit 7, `Windows` request value): see `docs/licensing-windows.md`.
- Rendering of M4: `Occa.Render/CourseOverprintRenderer.cs` (pixel space; on screen with 90 % alpha, exports place
  lower/upper purple in the colour order through `MapRenderer.Draw(..., belowPriority, drawBelow)`),
  `ContourRenderer.cs`; `MapScene.Item.Priority` carries the colour priority. App: `Views/CoursePanel.xaml`,
  `Views/ContourPanel.xaml`, placement/drag of controls and autosave in `Views/MapView.xaml.cs`.

## Conventions

- C# 12, file-scoped namespaces, nullable enabled, `Directory.Build.props` holds shared properties and the version.
- Comments explain the Mac counterpart when porting (name the Swift type) so both codebases can be kept in step.
- Tests: xUnit, fixtures under `tests/Occa.Core.Tests/Fixtures`, network tests use `[SkippableFact]` and run only when
  `OCCA_ESRI_API_KEY` is set.
- Package versions are pinned; check nuget.org before bumping (Windows App SDK 1.8.x line, not 2.x, until decided).
